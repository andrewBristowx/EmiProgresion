# Changelog

## 0.1.0-alpha.2
- Adds a separate `emiprogresion:kanto` adventure dimension using Overworld-style terrain.
- Keeps the normal world dedicated to spawn, housing and survival.
- Adds an 8000-block Kanto world border.
- Adds travel commands between the normal world and Kanto.
- Defines the first campaign prototype: initial town → Route 1 → Brock.
- Adds configurable Brock coordinates and a configurable Cobbleverse Brock structure id.
- Adds validation and admin teleport helpers.
- Does not guess Cobbleverse structure ids; natural-gym suppression remains pending exact `COBBLEVERSE-DP-v31` identifiers.

## 0.1.0-alpha.1
- Initializes the server-side Fabric project.
- Defines Kanto planning radius, spawn protected core and housing ring.
- Adds initial planning/status/config commands.
